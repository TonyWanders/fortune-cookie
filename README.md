A program that writes one original line of fortune-cookie wisdom aimed
at a software developer to `/output/entry.txt`, for the make.fun
competition
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 84 characters, inside the 1 to 120 gate.

## The entry

```
The estimate you gave in the meeting was a wish. The deadline heard it as a promise.
```
